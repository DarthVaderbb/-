二、你在控制什么？
想象一个物体沿水平直线移动，初始位置0米、速度0；目标位置1米。
质量m=1kg，存在与速度相反的阻力，阻力大小为b*v，b=1N·s/m。
控制器决定给物体施加多大力u。外界还可能施加扰动力d。
牛顿第二定律：m*a = u + d - b*v。
程序写成：a = (applied + external - damping * v) / mass。
下一步速度：v = v + a*dt。
下一步位置：x = x + v*dt。
这里先更新速度，再用新速度更新位置，是一种离散近似。

变量对应
x：位置，单位m。
v：速度，单位m/s。
target：目标位置，单位m。
error = target-x：误差，单位m。
requested：控制器想施加的力，单位N。
applied：经过能力限制后真正施加的力，单位N。
external：外部扰动力，单位N。
dt=0.01s：每隔多长时间算一次，本实验每秒100次。

闭环过程：读实际位置→计算误差→计算控制力→更新运动→再读位置。
本教程的“测量”直接取仿真状态，没有加入真实传感器误差。
图的上半部分看位置，下半部分看控制力；两张图必须一起看。

第5周：先理解没有位置反馈会怎样
周一：阅读上面的变量说明，用纸画一个物体和受力箭头。
周二：执行 py control_lab.py --week 5。
程序前2秒施加1N力，2秒后控制力变为0。
观察：力撤掉后，位置还会变化吗？速度能立刻变成0吗？
解释：物体有惯性；撤掉力不等于速度立即归零。阻力逐渐使它减速。
本周没有“到1米就停”的反馈，所以不用期待它停在1米。
周三：找到simulate函数中的mass, damping, dt, target那一行。
只把damping从1.0改成2.0，保存后重新运行；与原图比较。
预期：同一施力条件下阻力更大，移动距离更小。之后恢复damping=1.0。
周四：找到requested = 1.0 if t < 2.0 else 0.0。
这是“若t小于2则取1，否则取0”的简写。将2.0改成1.0，观察施力时间的影响，再恢复。
周末：用自己的话解释“输入是力，输出是位置，状态包含位置和速度”。
提交：一张图和150字说明。能解释为什么定时施力不能可靠地停在目标位置即可过关。

第6周：P控制——偏得越远，纠正力越大
规律：u=Kp*(target-x)。Kp单位是N/m。
举例：目标1m，实际0.2m，误差0.8m；Kp=4时控制力3.2N。
实际1.1m时误差-0.1m，控制力-0.4N，方向反过来。
周一：自己算上面两种位置下的误差和力。
周二：执行 py control_lab.py --week 6，比较Kp=1、4、9。
周三：看哪条线首次接近目标较快，哪条冲过目标较多。
首次到达目标不等于之后稳定停住；注意观察后面的往返变化。
周四：找到cases_for函数里week == 6分支，将(1, 4, 9)改成(1, 4, 16)，比较后恢复。
周末：填表：Kp、是否越过目标、最大越过量、最后5秒平均绝对误差、最大控制力。
终端提供后三项指标。overshoot表示最大越过量；MAE表示平均绝对误差。
这些指标只描述本次30秒实验，不是稳定性证明。
思考：已接近目标但速度还很大，单看位置误差会不会制动太晚？
提交：三条P曲线和解释。不要总结为“Kp越大越好”。

第7周：PD控制——加入与速度相反的制动力
本例目标位置固定：u=Kp*(target-x)-Kd*v。
Kd单位为N·s/m。v>0时，-Kd*v为负，帮助减速。
例如误差0.2m、速度1m/s、Kp=4、Kd=2，u=0.8-2=-1.2N。
虽然还没到目标，但速度很大，控制器已经开始制动。
周一：手算上面的力，解释负号。
周二：执行 py control_lab.py --week 7。
先比较Kp=4、Kd=0/2/4三条曲线；Kd=0就是P控制。
观察：增加Kd可能减少振荡，但也可能使接近目标变慢。
周三：比较Kp=9的两条曲线，一条不限力，一条限制为±5N。
为什么这里另设Kp=9？Kp=4初始要求4N，±5N限制可能看不出作用；Kp=9初始要求9N才会触发限幅。
周四：打开week7_results里的case5.csv。
requested_force_N是期望力，applied_force_N是实际施力，看前几行的9N如何变成5N。
CSV可用表格软件查看；只看数据，不要覆盖原始记录。
周末：回答：为什么只看位置图不够？执行器达不到期望力会改变什么？
通过：能解释位置误差项、速度制动项和限幅。
注意：此处D项对测得速度起作用。时变目标轨迹还要考虑目标速度；真实噪声也会影响D项。

第8周：I项——处理持续扰动造成的残余误差
程序在第5秒加入持续+1N外力，方向朝位置增大的方向。
PD最终静止时v≈0，需要控制力约-1N平衡外力。
由于u=Kp*(target-x)，Kp=4时必须有error≈-0.25m，即位置约1.25m。
这不是PD程序写错，而是比例项要靠非零误差产生平衡力。

积分integral把每一小段误差累积：integral += error*dt。
PID：u=Kp*error+Ki*integral-Kd*v。
Ki单位N/(m·s)。误差持续存在时积分变化，提供额外控制力。
周一：先手算上面1.25m的平衡位置。
周二：执行 py control_lab.py --week 8，比较PD与两条PID。
周三：观察第5秒后的偏移、回归速度、是否再次振荡。
PD应趋近1.25m；PID在这些参数下会逐渐回到1m附近，30秒有限时长内可能还有少量误差。
周四：在week8分支把Ki=0.5改成0.2，比较回归速度，再恢复。
如果改Ki参数，也一起修改对应的显示标签，避免图例误导。
周末：写一页总结：外扰是什么；PD为何有残余误差；I项怎样改变它；代价是什么。

积分保护说明
程序把integral限制在[-5,5]，这是为了演示积分限幅。
这不是适合所有系统的通用参数，也不等于完整的抗执行器饱和方案。
如控制力长时间饱和，积分可能继续累积，解除饱和后出现过冲。
本阶段先认识现象；以后再学习条件积分、反算抗饱和等方法。

三、怎样阅读程序，不必一次看懂全部
第一遍只找simulate函数中的a、v、x三行：它们是被控对象。
第二遍找error、requested：它们是控制器。
第三遍找limit：它是执行器限制。
第四遍找external：它是扰动。
cases_for决定每周做哪些对比实验；main负责命令选择、保存数据和画图。
暂时不用完全理解argparse、csv等工具库，也能先观察实验。
但最终要能自己写下面的最小闭环，而不只会运行现成文件。

最小PD闭环（另存minimal_pd.py，在IDLE按F5运行）
x = 0.0
v = 0.0
dt = 0.01
for step in range(1000):
    error = 1.0 - x
    force = 4.0 * error - 2.0 * v
    acceleration = (force - 1.0 * v) / 1.0
    v = v + acceleration * dt
    x = x + v * dt
print("10秒后的实际位置：", x)

这是整个控制实验的核心，其余大部分代码负责比较和展示。
其中force里的-2*v是控制器主动制动；acceleration里的-1*v是物体本身的阻力，来源不同。
